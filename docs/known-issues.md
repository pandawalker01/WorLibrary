## WL-001：EPUB 选区颜色未在正文显示

- 状态：已修复，待真实 Worker 环境复验
- 优先级：P0
- 首次记录：2026-10-20
- 影响范围：通过 Cloudflare Worker 本地地址打开 EPUB 后，用户在选区浮层中选择任一颜色。
- 预期：点选颜色后，应立即在选中的 EPUB 文本上显示对应颜色；点击“保存摘录”后，刷新或重新打开书籍仍可显示。
- 当前观察：此前复用临时 EPUB.js annotation 会让它在关闭浮层或章节重载后脱离内部 annotation map，导致正文没有稳定可见的颜色。
- 修复：保存有显式颜色的摘录时，先移除临时 annotation，再创建持久 annotation；未选颜色时只保存摘录文本，不创建正文高亮。旧摘录继续按默认规则显示。
- 自动化证据：`tests/qa/reader-e2e-flow.spec.ts` 验证未选颜色时 annotation 为零；选择玫红、保存并刷新后 annotation 仍存在。
- 剩余验收：在真实 `http://localhost:8787` Worker 环境手动选择三种颜色各一次，验证即时可见、保存后重开仍可见；通过后可将状态改为“已关闭”。
